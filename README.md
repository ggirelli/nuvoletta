*Private thoughts. Safely kept.*

Nuvoletta is an encrypted note app written in Rust with Dioxus. Notes are Markdown, stored as
encrypted files in a vault directory that you control, with no database and no plaintext leaving
your device.

**Status:** pre-release (`0.1.0-rc.1`). Not audited, not for sensitive data yet.

> [!IMPORTANT]
> Nuvoletta is fully vibe coded: an AI assistant (Claude) writes all of its code, tests, formats and
> docs, and the maintainer directs and reviews the work. It is tested, not audited, and no
> independent security review has taken place, so do not rely on it for sensitive notes yet and keep
> backups. It is provided as is, without warranty, under the [MIT license](LICENSE). Read the
> [disclaimer](DISCLAIMER.md) before relying on it.

See [PLAN.md](PLAN.md) for the design and roadmap.
