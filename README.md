# Nuvoletta

*Private thoughts. Safely kept.*

Nuvoletta is an encrypted note app written in Rust with Dioxus. Notes are Markdown, stored as
encrypted files in a vault directory that you control, with no database and no plaintext leaving
your device.

**Status:** pre-alpha, design phase. Not for sensitive data.

See [PLAN.md](PLAN.md) for the design and roadmap.
