# User guide

Plain-language help for using nuvoletta. The design documents (threat model, formats, protocol) are
under *Design*; these pages tell you what to do.

!!! warning "Pre-alpha, not audited"
    nuvoletta is pre-alpha and has **not** had an independent security review. Do not rely on it for
    highly sensitive material yet, and keep your own backups. See [Security and privacy](security-and-privacy.md).

- [Getting started](getting-started.md): create a vault, write down the recovery key, write.
- [Backup and restore](backup-and-restore.md): what to back up, how to restore, what not to sync.
- [Sync setup](sync-setup.md): a synced folder or WebDAV.
- [Lost or stolen device](device-loss.md): joining a new device, and what a lost device still has.
- [Recovery key](recovery-key.md): keeping it, using it, replacing it.
- [Security and privacy](security-and-privacy.md): what is protected, what leaks, what is not promised.
- [Privacy policy](privacy-policy.md): what data goes where (nothing leaves your devices except to the
  sync location you choose).
