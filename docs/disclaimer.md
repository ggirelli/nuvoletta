# Disclaimer: fully vibe coded

Nuvoletta is written entirely by an AI coding assistant, Claude (made by Anthropic), working in
[Claude Code](https://claude.com/claude-code). Its code, tests, fuzz targets, scripts, formats,
protocols, documentation, plans and this disclaimer are generated by the assistant in conversation
with the project's maintainer, who describes what they want, reviews the results and asks for
changes. No line of it is written by hand.

## What that means

- **It is tested, not audited.** Changes are checked with automated checks (`just ci`: formatting,
  lints, unit, integration and property tests, dependency policy), fuzzing, and an internal review
  that was itself AI-assisted ([Internal security review](SECURITY_REVIEW.md)). Nobody has
  reviewed the code line by line the way a careful human-written project would be, and no
  independent security audit has taken place.
- **Do not rely on it for sensitive notes yet.** Nuvoletta encrypts your notes, but encryption code
  that nobody has independently audited can have mistakes that tests do not reveal. Until an audit
  happens, keep anything you cannot afford to lose or have exposed somewhere else as well. The
  known limits are in the [threat model](THREAT_MODEL.md) and in
  [Security and privacy](user/security-and-privacy.md).
- **Keep backups.** It is a pre-release. Bugs that lose or corrupt data are possible, and formats
  may still change. See [Backup and restore](user/backup-and-restore.md).
- **Expect rough edges.** Please [report bugs](https://github.com/ggirelli/nuvoletta/issues), and
  report security problems privately as described in [SECURITY.md](https://github.com/ggirelli/nuvoletta/blob/main/SECURITY.md).
- **No warranty.** As the [license](https://github.com/ggirelli/nuvoletta/blob/main/LICENSE) says, the software is provided "as is".

## Why say it

Because it is true, and because you should know how the software you trust with your notes was
made. The commit history shows the whole process: each commit is co-authored by the assistant. How
the work is planned is in [PLAN.md](plan.md).
